# Campus Library Manager

A Python program for borrowing and returning books, magazines and DVDs.

To run the demo from this repository:

```sh
cd library_manager
python3 main.py
```

You need Python 3.12 or later, with no extra packages.
The demo includes deliberate mistakes to show how the program handles them.

The [project README](library_manager/README.md) has the reflection answers.
You can also read the [saved demo output](library_manager/output.txt).
